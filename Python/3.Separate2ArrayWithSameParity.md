# Reto de código: Puedes resolverlo??

Coloreando el Array

`Lenguaje/s`: Todos

`Valor`:  2 pts

`Fecha Límite`: Sin fecha límite.

## Planteamiento del problema

- Se te da un array que consiste en N enteros. Tu tarea es determinar si es posible colorear todos sus elementos en dos colores de tal manera que las sumas de los elementos de ambos colores tengan la misma paridad y cada color tenga al menos un elemento coloreado.

Por ejemplo, si el array es [1, 2, 4, 3, 2, 3, 5, 4], podemos colorearlo de la siguiente manera: [**1, 2**, 4, **3**, 2, 3, 5, 4], donde la suma de los elementos azules (**NEGRITA**) es 6 y la suma de los elementos rojos (SIN NEGRITA) es 18.

## Entrada

- La primera línea contiene un entero T, el número de casos de prueba.
- Cada caso de prueba comienza con una línea que contiene un entero N, la cantidad de elementos del array.
- La siguiente linea contiene N enteros a_i, los elemtos del array.

```md
T
N
a1 a2 a3...aN
```

## Restricciones

1 <= T <= 1000.

2 <= N <= 50.

1 <= a_i <= 50.

## Salida

Para cada caso de prueba, imprime "YES" (sin comillas) si es posible colorear el array en dos colores de tal manera que las sumas de los elementos de ambos colores tengan la misma paridad y cada color tenga al menos un elemento coloreado, y "NO" en caso contrario.

Puedes imprimir "YES" y "NO" en cualquier caso (por ejemplo, las cadenas "yES", "yes" y "Yes" serán reconocidas como respuestas correctas).

## Ejemplo 1

Input:

```txt
7
8
1 2 4 3 2 3 5 4
2
4 7
3
3 9 8
2
1 7
5
5 4 3 2 1
4
4 3 4 5
2
50 48
```

Output:

```txt
YES
NO
YES
YES
NO
YES
YES
```

Nota:

- El primer caso de prueba está descrito en el enunciado.
- En el segundo caso de pruebas, solo hay dos formas de colorear
[4, 7] y [4, 7], pero en ambos casos la paridad de las sumas es diferente.
- En el tercer caso de pruebas, puedes colorear [3, 9, 8] y 12 y 8 son ambos pares.
